# Visuals — self-contained explainers (HTML/SVG, corpus visual language)

Each file opens in a browser with no build step and no external asset. Published as
private artifacts in Swaroop's gallery; the URLs are the shareable form, these files are
the source. Built in the corpus visual language (`../visual-language/`): purple edges,
blue spine, green sends, teal storage, amber external, red refusals.

| File | What it is | Artifact |
|---|---|---|
| `buddy-stages.html` | **CURRENT.** The three-stage traffic plan with a live throughput dial: drag it and the pod ledger, the verdict and each stage's capacity bar recompute; overload a stage and a backlog stacks at the component that chokes. Per-stage letter trace. Companion to `design/scaling-stages.md`. | `claude.ai/code/artifact/76fc79d1-6cac-4378-ba29-84b61a0982cd` |
| `buddy-mailroom.html` | The whole system explained for a ten-year-old — 12 illustrated sections (doors, tray, reader, address book, rulebook, gate, postman, window) plus an honest scorecard on whether Python is the right fit. Each section carries a "grown-up words" box mapping the story to the code. | `claude.ai/code/artifact/2c4e096e-0701-4663-8d87-e845c2ebf44e` |
| `buddy-phases.html` | Superseded by `buddy-stages.html` (this was the 5-phase cut). Keeps the clickable data model: 19 tables by owning module, built vs designed, canon columns on click. | `claude.ai/code/artifact/e93b4a4e-434d-4710-a393-c4f614594c52` |
| `spine-at-50k.html` | The single-scene version of the log architecture (stage 3), lane-by-lane. | `claude.ai/code/artifact/be8a9885-6440-4d1b-8e7b-34cca1990126` |
